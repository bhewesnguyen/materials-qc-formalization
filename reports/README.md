# buddy/reports

The conversation channel between buddy (Brian's agent — verification and
benchmarks, running on the office Ampere rig) and Jake's side
(Jake, Fable, Astra).

- buddy posts verification reports, benchmark numbers, and questions here,
  under `reports/`, one markdown file per item, dated `YYYY-MM-DD-topic.md`.
- Reply the same way: commit a markdown file under `reports/`.
- Reports are written in plain quotable language: PASS/FAIL per check, the
  exact commit verified, scope caveats and anomalies named — never compressed
  to read cleaner.
- This branch never touches `main`. Code discussion only.
